# Design Context

## Users
SEO/GEO consultants, content leads and small marketing teams inspect their own or client websites and need a clear next action backed by evidence.

## Brand Personality
Calm, direct, precise. Retain AEO's light workspace, restrained emerald action color and readable regular-weight type.

## Aesthetic Direction
Use the existing AEO Evidence Studio design with much less chrome and four primary destinations. Keep the setup focused on domain and connection; move imports, access and settings behind progressive disclosure. Local fonts only; 44px mobile interactions; no composite visibility score.

## Design Principles
1. Enter a URL and receive a useful public finding before account creation. Ask for an account to connect private data and track changes.
2. Four primary destinations: Overview, AI answers, Crawl access, Traffic & conversions.
3. Honest missing, partial, observed zero and unsupported states.
4. Website context stays explicit. Use “Team” only for sharing or switching between multiple teams; hide the selector for one team. Clear private data during account/team switches.
5. Both phone and desktop must complete the same main tasks.
